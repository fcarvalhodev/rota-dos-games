# Rota dos Games

O apoio federal aos games no Brasil de 2003 a 2026: editais, Lei Rouanet, imposto dos consoles, Marco Legal dos Games e o pacote de 2026, governo por governo. Cada item traz a fonte.

Parte da série [Rotas](https://fcarvalhodev.github.io/rotas/).

Site estático, sem build. Publicado pelo GitHub Pages a partir da branch `main`.
